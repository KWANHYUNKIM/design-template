# 영상 플랫폼 홈 — 측정된 디자인 시스템

- 측정일 2026-08-10 · `https://www.youtube.com/` 홈(로그인 상태)
- 뷰포트 **1536 × 747** 로 고정해 측정 (창 리사이즈 중 1920→1524 로 흔들려 재측정)
- 표본: 표시 중인 노드 2,713개 · shadow root 0개(Polymer shady DOM 이라 light DOM 조회로 전수 수집됨)
- 도구: `.claude/skills/design-clone/references/deep-extract.md`

> 측정값과 거기서 도출한 규칙만 적는다. 원문 카피·채널명·영상 제목·이미지 URL은 적지 않는다.
> 로그인 상태로 측정했으므로 좌측 레일의 개인 구독 목록은 **개수와 좌표만** 취하고 이름은 기록하지 않는다.

## ⚠️ 측정 환경의 한계 — 먼저 밝힌다

이 브라우저에서 대상 페이지가 **정상 렌더되지 않았다.** 재현에 영향을 주므로 먼저 적는다.

| 증상 | 실측 |
|---|---|
| 문서가 스크롤되지 않음 | `documentElement.scrollHeight` = `innerHeight` = 747 로 고정 |
| 스크롤 컨테이너 부재 | `scrollHeight > clientHeight` 인 요소 0개 |
| 실제 휠 이벤트도 무효 | `computer.scroll` 10틱 후 화면 동일 |
| 썸네일 미도색 | `img` 104개 중 `naturalWidth>0` 은 20개 |

**골격 좌표는 `getBoundingClientRect` 로 정상 취득된다.** 첫 세션에서 시간이 지나며
카드가 37개까지 차올랐고 `#contents` 높이가 **5,079px**, `ytd-app` 이 **5,207px** 로 측정됐다.
즉 DOM 은 쌓이는데 뷰포트가 그것을 클리핑하고 있다. 아래 골격은 그 상태에서 잰 값이다.

**따라서 피드 깊이(총 카드 수·셸프 반복 주기)는 확정값이 아니다.** 1화면분 + 첫 셸프까지만 신뢰한다.

## 골격 — 3분할 고정 레이아웃

세로로 흐르는 랜딩이 아니다. **상단바 + 좌측 레일 + 우측 스크롤 영역**의 앱 셸이다.

| 블록 | x | y | w | h |
|---|---|---|---|---|
| 상단바 | 0 | 0 | 전폭 | **56** |
| 좌측 레일 | 0 | 56 | **240** | 811 (내용에 따라 신축) |
| 필터 칩 바 | 240 | 56 | 1284 | **56** |
| 카드 그리드 | 240 | 112 | **1284** | 5,135 |

좌측 레일 내부는 `guide-section-renderer` **6개**가 구분선으로 나뉜다 —
높이 105 / 385 / 345 / 177 / 217 / 64, 그 아래 링크 푸터 397.
★ **레일 푸터가 397px 로 레일 전체의 1/3을 먹는다.** 약관·정책 링크를 접지 않고 편다.

## 그리드

- 열수 **3** (`--ytd-rich-grid-items-per-row: 3`)
- 거터 **16px** (`--ytd-rich-grid-gutter-margin`)
- 카드 **401 × 358** · `margin-bottom: 32px`
- 썸네일 슬롯 비율 **16:9** — `padding-top: 225.738px` 가 76건 검출됨 (225.738 ÷ 401 = 56.3% = 9/16)
- 세로 셸프 슬롯 비율 **9:16** — `padding-top: 351.6px` 가 10건 (198 × 16/9 = 352)

★ **1536px 폭에서 3열이다.** 카드가 401px로 크고, 열을 늘리는 대신 카드를 키운다.

## ★ 이 시스템만의 것

1. **앱 셸이다.** 세로로 흐르는 페이지가 아니라 56px 바 + 240px 레일 + 스크롤 영역의 3분할 고정
2. **자간 단계가 0이다.** 전 조합 `normal` — 크기·굵기만으로 위계를 만든다
3. **타입 상한이 20px 이다.** 히어로가 없고, 가장 큰 글자가 셸프 제목이다
4. **그림자가 없다.** 카드가 떠 있지 않고 썸네일 라운드로만 구분된다
5. **포인트색을 UI에서 뺀다.** 무채색 3단계 + 파랑 링크 2건
6. **1536px에서 3열.** 열을 늘리지 않고 카드를 401px까지 키운다

### `templates/ref-12-youtube-mulddae.html` — 물때 (갯벌 조간대 물때 피드)

**1차 대조에서 두 축이 어긋났고 둘 다 원인이 달랐다.**

1. **카드 높이 −15.0%** (339 → 288). CSS 문제가 아니라 **제목이 1줄로 끝난 것**이었다.
   원본은 2줄로 접힌다. 발명한 지점명이 8~12자로 짧아 한 줄에 들어가 버렸다.
   제목을 24~38자 대역으로 올리자 12장 전부 2줄이 되며 310px로 균일해졌다(−8.6%).
   ★ `deep-extract.md` 가 예고한 그대로다 — **높이 차이는 CSS가 아니라 글자 수다.**
2. **칩 개수 14 → 10.** 습관적으로 「적당히 10개」를 집었다. 세어서 14로 맞췄다.

**끝까지 맞추지 못한 것 둘** (고치지 않고 남긴다)

- **라운드 분포.** 원본 최다는 20px(182건)인데 산출물엔 사실상 없다(검색창 양끝뿐).
  원본 칩의 실제 라운드를 못 쟀다 — `yt-chip-cloud-chip-renderer` 를 재면 껍데기라 `0px` 가 나오고
  안쪽 알약까지 뚫지 못했다. **모르는 값을 추측해 채우지 않았다.**
- **포인트색이 쓰인 자리.** 원본 측정에서 파랑은 텍스트 2건, 산출물은 레일 알림 점의 배경 3건이다.
  원본 UI에도 같은 자리의 점이 있으나 이번 표본에서 렌더되지 않아 대조가 불가능했다.

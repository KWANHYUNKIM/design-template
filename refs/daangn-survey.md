## ★ 이번 답사에서만 나온 것 — 토큰 문서를 보정한다

### 1. 히어로 워드 롤링 — 이 페이지의 유일한 자동 모션

```
"…에서 [ 아이폰 ] 찾고 계신가요?"
         └ overflow:hidden 슬롯 66×38
           안에 flex column 9칸 (아이폰/알바/중고차/원룸/러닝 모임/맛집/동네친구/자전거/카페)
```

- 슬롯 **폭이 단어마다 바뀐다** (아이폰 66 → 맛집 49). 폭도 같이 애니메이션한다
- 세로로 밀려 올라가며 **이전 단어가 흐려지고 다음 단어가 들어온다** (스크린샷에서 두 단어가 겹친 순간 포착)
- 칸 높이 38 = 헤드라인 행간과 동일
- ⚠️ **전환 간격·이징은 못 쟀다.** `document.visibilityState === 'hidden'` 이라
  rAF가 멈춰 샘플이 전부 고정값이었다 (`opacity:0.26` 에 얼어붙음). N4에 가정으로 적는다

### 2. 검색 범위 = 데스크톱인데 **바텀시트**

| 항목 | 실측 |
|---|---|
| 딤 | `rgba(0,0,0,0.455)` 전면 |
| 시트 | **전폭** · h342 · `radius 20px 20px 0 0` · `#fff` |
| 리스트 | `padding:10px 0` · 7항목 |
| 항목 | h**46** · `padding:12px 16px` · 16/400/24 |
| 선택된 항목 | 16/**700**/24 · **`#ff6600`** + 우측 체크 |

★ **여기서 포인트 오렌지가 UI에 쓰인다.** `refs/daangn.md` 는 "포인트색이 텍스트·배경·테두리에 0건,
로고와 아이콘에만" 이라고 적었는데 — **닫힌 상태만 쟀기 때문이다.**
열어 보면 선택 상태 텍스트가 오렌지다. **답사 없이 측정만 하면 이걸 놓친다.**

> 규칙 보정: 포인트색은 **평상시 UI에 안 쓰고, 선택된 하나에만 쓴다.**

### 3. 섹션마다 폭이 다르다

754 → 900 → 960 → 1308. 한 폭으로 통일하는 습관(이 저장소의 기본값)과 정면으로 다르다.
**좁은 폼(754)이 페이지 한가운데 떠 있고 아래로 갈수록 넓어진다.**

로고 하나. GNB 없음. 검색·로그인·장바구니도 없다. h64 에 sticky.
**네비게이션을 헤더가 아니라 본문 한가운데(검색바 + 카테고리 8칸)가 진다.**

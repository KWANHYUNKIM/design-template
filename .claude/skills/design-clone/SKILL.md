# 페이지 복제 — 뼈대까지 옮긴다

`design-ref` 는 **토큰**을 옮긴다(타입·간격·색·라운드·그림자·모션).
그것만으로도 숫자는 맞지만 **안 닮아 보인다.** 뼈대가 다르기 때문이다.

> REF 06은 LG 시스템을 6축 전부 맞췄는데도 "왜 안 똑같냐"는 말이 나왔다.
> 자간 3단계·16px 간격·2겹 그림자까지 같았지만,
> 원본은 히어로 캐러셀 → 프로모션 타일 → 카테고리 그리드 순이고
> 산출물은 계산기 → 카드 → 후기 순이었다. **구성이 달랐다.**

이 스킬은 그 층을 마저 옮긴다.

## 두 가지 출력 모드 — 먼저 정한다

| 모드 | 출력 위치 | 얼마나 닮는가 | 공개 |
|---|---|---|---|
| **연구용 클론** | `_clone/<회사>/` | 뼈대·비율·좌표까지 최대한 | ❌ 커밋·배포 안 함 |
| **공개 산출물** | `templates/ref-NN-*.html` | 뼈대는 같고 **브랜드·콘텐츠는 발명** | ✅ 갤러리에 올림 |

**연구용 클론은 구조를 익히려고 만드는 것이다.** 클론 코딩은 디자인 교육의 표준 방식이고,
남의 페이지를 뜯어 보며 배우는 것 자체는 정상적인 작업이다.
다만 그 결과물을 **그대로 공개하면** 성격이 달라진다.

`_clone/` 은 `.gitignore` 에 넣어 커밋되지 않게 한다.

## 선 — 공개 산출물에만 적용된다

공개하는 순간 아래는 못 가져온다. 취향이 아니라 사칭이 되는 지점이다.

- ❌ 로고·워드마크·브랜드 심볼
- ❌ 실제 제품명 (그 회사가 파는 물건의 이름)
- ❌ 그 회사의 사진·일러스트·아이콘 원본
- ❌ 실제 카피 문장
- ❌ 그 회사인 것처럼 보이게 하는 모든 것 — 회사명·도메인·실존 인물

**뼈대·비율·컴포넌트 구성·좌표는 가져온다.** 이건 어느 회사의 소유물도 아니다.
`scripts/verify.mjs` 의 `ref-*` 검사 3종이 자동으로 막는다.

## 순서

### 1. 모드 결정

연구용인지 공개용인지 **먼저** 정한다. 나중에 바꾸면 콘텐츠를 전부 다시 써야 한다.

### 2. 깊은 추출 — `references/deep-extract.md`

`design-ref` 의 추출이 **분포**를 잰다면 이쪽은 **구조**를 뜬다.

```
① 섹션 골격    각 섹션의 역할·높이·배경·자식 컴포넌트 수
② 그리드 지도  grid/flex 컨테이너마다 열 구성·gap·자식 수
③ 컴포넌트 인벤토리  반복되는 블록의 종류와 개수 (카드 24개, 배너 4개…)
④ 이미지 슬롯  각 이미지의 표시 크기·비율·object-fit·섹션 내 위치
⑤ 타입 역할표  크기별로 "어디에 쓰였는지" (h1 자리인가 캡션 자리인가)
⑥ 좌표         주요 블록의 x·y·w·h — 겹침과 정렬을 재현하는 데 쓴다
```

**끝까지 스크롤한 뒤 잰다.** 캐러셀·아코디언은 각 상태를 따로 잰다.

### 3. 골격 먼저 세운다 — 콘텐츠는 나중

**빈 상자로 페이지를 먼저 완성한다.** 섹션 높이·그리드 열수·이미지 슬롯을 회색 박스로 두고,
원본과 좌표를 대조해 뼈대가 맞을 때까지 조정한다.

콘텐츠를 먼저 넣으면 텍스트 길이에 밀려 뼈대가 어긋나고, 그때는 원인을 못 찾는다.

### 4. 콘텐츠를 채운다

- **연구용:** 원본과 같은 자리에 같은 성격의 더미를 넣는다(길이만 맞춘다)
- **공개용:** 발명한 브랜드·제품·수치로 채우되 **글자 수 대역을 맞춘다.**
  원본 제품명이 6~10자면 발명한 이름도 그 대역으로 — 안 그러면 카드가 다르게 접힌다

### 5. 좌표 대조 — 이 스킬의 합격선

같은 추출 스크립트를 산출물에 돌려 **블록별 좌표를 대조한다.**

| 축 | 합격선 |
|---|---|
| 섹션 높이 | 각 섹션 ±15% |
| 그리드 열수 | 전 구간 일치 |
| 컴포넌트 개수 | 카드·배너·버튼 수 ±1 |
| 이미지 슬롯 비율 | ±0.05 |
| 주요 블록 y좌표 | 누적 오차 ±10% |
| 타입 역할 | 크기별 쓰임이 같은 자리 |

**높이가 15%를 넘게 벌어지면 콘텐츠 분량이 다른 것이다.** 글자 수를 조정한다.

### 6. 검증 · 기록

`design-ref` 와 같다 — `verify.mjs` 오류 0, iframe 실측 3폭, 선 검사 3종.
공개 산출물이면 `refs/<회사>.md` 에 좌표 대조표를 append 한다.

## design-ref 와의 관계

| | design-ref | design-clone |
|---|---|---|
| 재는 것 | 값의 **분포** | 구조의 **좌표** |
| 결과 | 같은 시스템, 다른 물건 | **같은 뼈대**, 다른 브랜드 |
| 쓸 때 | 시스템을 배우고 싶을 때 | 그 페이지처럼 보이게 하고 싶을 때 |

**둘을 같이 쓴다.** design-ref 로 토큰을 잡고, design-clone 으로 뼈대를 세운다.
토큰만 맞추면 안 닮고, 뼈대만 맞추면 싸구려 모조가 된다.

# 재구성 — 골격을 먼저 세운다

## 원칙: 빈 상자로 페이지를 먼저 완성한다

콘텐츠를 먼저 넣으면 **텍스트 길이에 밀려 뼈대가 어긋나고, 그때는 원인을 못 찾는다.**
회색 박스만으로 좌표가 맞을 때까지 세운 뒤에 채운다.

```html
<!-- 1단계: 뼈대만. 모든 블록이 회색 상자다 -->
<section class="s-hero"  style="height:500px;background:#ddd"></section>
<section class="s-promo" style="height:224px;background:#ccc"></section>
<section class="s-grid"  style="height:665px;background:#ddd"></section>
```

이 상태에서 추출 스크립트를 돌려 **원본과 y좌표·높이를 대조**한다. 맞으면 다음으로 간다.

## 2단계: 그리드를 넣는다

측정한 `cols` · `gap` · `kids` 를 그대로 옮긴다.

```css
/* 원본: grid · 5열 · gap 16px · 자식 15개 */
.s-grid .row{display:grid;grid-template-columns:repeat(5,1fr);gap:16px}
```

**자식 수도 맞춘다.** 15개면 15개를 넣는다 — 12개만 넣으면 섹션 높이가 어긋난다.

## 3단계: 이미지 슬롯을 비율로 채운다

원본 이미지는 가져오지 않는다. **같은 비율의 자리만 만든다.**

```css
.slot{aspect-ratio:16/9;background:linear-gradient(135deg,#e8e8ea,#cfcfd3)}
```

나중에 발명한 사진이나 CSS 도형으로 바꾼다. **비율이 같으면 뼈대는 유지된다.**

## 4단계: 타입을 역할표대로 얹는다

크기·굵기만이 아니라 **어느 자리에 몇 글자로** 쓰였는지를 따라간다.

| 원본 | 자리 | 산출물 |
|---|---|---|
| 36/700/50 · h1 · 12자 · 1줄 | 히어로 제목 | 같은 크기, **12자 대역** |
| 19/600/26 · h3 · 8자 · 1줄 | 카드 제목 | 같은 크기, 8자 대역 |
| 14/400/20 · p · 45자 · 2줄 | 카드 설명 | 같은 크기, 45자 대역 |

★ **글자 수 대역을 맞추는 것이 CSS를 맞추는 것만큼 중요하다.**
원본 제품명이 6~10자인데 발명한 이름이 18자면 카드가 두 줄로 접혀 높이가 달라진다.

## 5단계: 콘텐츠를 채운다

이 시점에 뼈대는 이미 맞아 있다. 글자 수 대역만 지키면 무너지지 않는다.

- **연구용 클론:** 같은 성격의 더미. 로렘 대신 실제 한국어 문장을 쓰되 길이만 맞춘다
- **공개 산출물:** 발명한 브랜드·제품·수치. 선 검사 3종을 통과해야 한다

## 6단계: 좌표 대조 — 합격선

```
섹션 높이      각 섹션 ±15%
그리드 열수    전 구간 일치
컴포넌트 개수  카드·배너·버튼 ±1
이미지 비율    ±0.05
y좌표 누적     ±10%
타입 역할      크기별 쓰임이 같은 자리
```

### 안 맞을 때 어디를 보는가

| 증상 | 원인 | 고칠 곳 |
|---|---|---|
| 섹션 높이가 크다 | 글자 수가 많아 줄이 늘었다 | **콘텐츠 길이** (CSS 아님) |
| 섹션 높이가 작다 | 자식 개수가 모자라다 | 카드·배너 수 |
| 아래로 갈수록 y가 밀린다 | 앞 섹션 오차가 누적됐다 | **위에서부터 순서대로** 잡는다 |
| 열수는 같은데 폭이 다르다 | `max-width` 또는 좌우 padding | 컨테이너 폭 |
| 카드가 다르게 접힌다 | 제목·설명 글자 수 대역 | 텍스트 길이 |

## 하지 않는 것

- **원본 HTML을 복사해 붙이지 않는다.** 측정값을 보고 다시 짠다 —
  붙여넣으면 그 회사의 클래스명·주석·데이터 속성·인라인 스크립트가 그대로 딸려 온다
- 원본 CSS 파일을 링크하지 않는다
- 로고 SVG의 `path` 데이터를 옮기지 않는다
- 공개 산출물에 원본 이미지 URL을 남기지 않는다 (`ref-asset-host` 가 막는다)

## 캐러셀·아코디언

원본이 여러 상태를 가지면 **각 상태를 따로 재고 따로 만든다.**
닫힌 상태만 재서 만들면 인터랙션이 빈 껍데기가 된다.

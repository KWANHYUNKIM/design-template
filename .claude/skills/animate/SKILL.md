# 모션 & 인터랙션

채점 8기준 중 **모션 & 인터랙션**은 이 저장소에서 가장 자주 5점이 나온 칸이다.
그래서 여기서 점수를 벌 여지는 거의 없고, **중복과 폴백 누락으로 잃을 여지만 남았다.**

핵심 규칙은 하나다. **직전 RUN과 "종류"가 달라야 한다.**
무엇을 조작하는가가 아니라 **무엇이 눈에 보이게 변하는가**가 달라야 한다.

## 1. 먼저 기법 대장을 대조한다

**28개 템플릿**이 실제로 쓴 것 (실측 · RUN30 시점). 만들기 전에 **내가 쓰려는 게 여기 몇 번 나왔는지** 센다.

| 기법 | 쓴 RUN 수 | 판단 |
|---|---|---|
| IntersectionObserver 리빌 | **28 / 28** | 기본기다. 이걸로는 점수가 안 난다 |
| `transition` 호버 | 25 | 기본기 |
| `requestAnimationFrame` 스크럽/카운트업 | 23 | 포화 |
| `@keyframes` 무한 루프 | 15 | 흔함 |
| `scroll-snap` 캐러셀 | 7 | 여지 있음 |
| Pointer Events 조작 | 6 (16·18·19·24·26·30) | 늘고 있다 — 종류로 승부할 것 |
| `conic-gradient` 회전 크롬 | 3 (09·14·21) | NOIR의 시그니처. 재사용은 리믹스로만 |
| `cursor:none` 커스텀 커서 | 2 (13·14) | 오래 안 썼다 |

숫자를 직접 다시 세는 법:
```bash
cd templates && for p in IntersectionObserver requestAnimationFrame ':hover' '@keyframes' scroll-snap conic-gradient pointerdown; do
  printf "%-24s %s\n" "$p" "$(grep -l "$p" run-*.html | wc -l)"; done
```

### ⚠️ 슬라이더는 이미 7번 썼다

`<input type="range">` 를 쓴 RUN: **15 · 16 · 17 · 19 · 20 · 21 · 23.**
최근 11개 RUN 중 7개다. **슬라이더는 이제 새 인터랙션이 아니다.**

> RUN21 크리틱: 조작 대상만 바꾼 같은 물건(옵션칩+슬라이더 → 가격·중량·납기 리드아웃)은
> 새 인터랙션이 아니다.

직접 세는 방법:

```bash
cd templates
grep -l 'type="range"' *.html          # 슬라이더 쓴 RUN
grep -ohE "addEventListener\('[a-z]+'" run-2*.html | sort | uniq -c | sort -rn
```

## 2. 조작형 인터랙션 1종을 설계한다

**장식이 아니라 쓸 수 있는 것 1개.** 리빌 10개보다 이것 하나가 설득력이 크다.

합격 조건 세 가지:

1. 방문자가 **직접 조작**한다 (스크롤만으로 되는 건 리빌이지 인터랙션이 아니다)
2. 조작하면 **화면이 바뀐다** — 숫자만 바뀌는 건 안 된다.
   슬라이더는 값이 아니라 **그림**을 바꿔야 한다
3. **직전 RUN과 종류가 다르다**

### 지금까지 쓴 종류

| RUN | 인터랙션 | 무엇이 보이게 바뀌었나 |
|---|---|---|
| 15 KERN | 텍스트 입력 + 웨이트 슬라이더 | 조판 견본이 실시간으로 |
| 16 KELVIN | **드래그 before/after** + 강도 슬라이더 | 사진의 색이 즉시 |
| 19 BASELINE | 항목칩 + 연도 슬라이더 | 그래프 + 판독 문장 |
| 20 BEVEL | 옵션 구성 | 가격·중량·납기·비교표 동시 |
| 22 ANCRE | 4축 구성 | 시계 그림 + 예상 일차 |
| 23 들물 | **시간 스크럽** | 단면도에 물이 차오르고 귀환 한계 재계산 |
| 24 GLEAN | `pointermove` / `pointerdown` | 조명 위치에 따라 도판이 바뀜 |
| 25 밤길 | 다이어그램 **노드 클릭** | 표의 기준점이 재설정됨 |
| 26 울림통 | **크로스오버 드래그** | 대역·부하 재계산 + **다음 섹션의 담당 유닛까지 바뀜**(모듈 간 결합) |
| 29 돋을 | 낮/밤 전환 | 같은 간판이 두 조건에서 다르게 읽힘 |
| 30 스민 | **드래그로 순서 재배열** | 겹침 순서가 바뀌면 3색 띠가 재배치되고 최종 색·색좌표·견뢰도가 갈림 |

### 아직 안 쓴 종류 (후보)

- ~~드래그로 **순서를 바꾸는** 것~~ → RUN30이 씀
- 지도/평면도 위 **지점 선택** → 그 지점의 단면·수치
- 텍스트를 **직접 고쳐 쓰면** 레이아웃이 재조판되는 것
- **비교 대상을 추가/제거**하면 표와 그래프가 함께 재구성
- 키보드/포커스로만 동작하는 것 (접근성이 곧 기능인 아카이타입)
- 시간이 아니라 **관점을 바꾸는** 축 (단면 ↔ 평면 ↔ 등고)

## 3. 모션은 2종 이상 혼합한다

리빌 한 종류만 있으면 모션 점수가 3에서 막힌다. 실제로 통한 조합:

- 스크롤 리빌 + 호버 + 카운트업
- 커서 인터랙션 + 글자 단위 리빌 + 마그네틱 버튼 (RUN13)
- 스크롤 스크럽 타임라인 + 라이브 조판 (RUN15)

**단, 더한다고 오르지 않는다.** RUN13·14는 T2 기법을 5종까지 늘리고도 30에 묶였다.
과한 모션은 그 자체로 AI 티의 신호다. **오케스트레이션된 한 순간이 흩뿌린 이펙트보다 세다.**

## 4. 폴백 — 여기서 감점이 난다

모션을 넣었으면 **네 가지를 반드시 함께** 넣는다. 빠지면 완성도 감점이고, 검사기가 세 개를 잡는다.

### ① 로드 폴백 (IntersectionObserver)

뷰포트 안에 이미 있는 요소는 즉시 표시한다. 없으면 첫 화면이 빈 채로 뜬다.

### ② `prefers-reduced-motion`

무한 애니 정지 + 스크럽/핀 해제. 리빌은 즉시 표시로.

### ③ 900px 이하

sticky pin·가로 스크럽류는 해제하고 `scroll-snap` 캐러셀 등으로 폴백한다.
안 하면 **빈 500vh 구간**이 생긴다.

### ④ `?capture=1` 캡처 모드

디자인 툴 반출용. 없으면 캡처 시 리빌 섹션이 **빈 프레임**으로, 가로 스크럽은 **1/5 패널만** 넘어간다.

```js
var CAPTURE=/[?&]capture=1/.test(location.search);
if(CAPTURE)document.documentElement.classList.add('capture');
var reduce=matchMedia('(prefers-reduced-motion:reduce)').matches||CAPTURE;
```

`.capture` 에서: 리빌 강제 표시 · 핀/스크럽 해제 후 세로로 펼침 · 무한 애니 정지 · 카운트업 최종값 고정

## 5. 모션에서 실제로 터진 함정

각각 실제 RUN에서 감점된 것이다.

| 함정 | 증상 | 처방 |
|---|---|---|
| 리빌 클래스명이 `.in` | 레이아웃 클래스와 충돌해 텍스트 div가 grid로 변함 | `.rise`/`.vis` 같은 고유명 |
| `scroll-behavior:smooth` | `scrollTo(0,0)`이 애니메이션이 되어 브라우저 스크롤 복원과 경합 | 초기 리셋 동안만 `auto`로 내렸다 되돌린다 |
| 마그네틱 버튼 스코핑 | 부모 섹션에 걸면 가장자리에서 수백px 튐 | 버튼 + 소반경 래퍼(`.mag-zone` padding~46px)에만 |
| `cursor:none` | JS 실패/로드 전에 커서가 사라짐 | `.js` 클래스 게이트로 폴백 유지 |
| 카운트업 단위 | 통째 텍스트면 좁은 칸에서 줄바꿈, `nowrap`이면 가로 오버플로 | `<span>` 분리 + `nowrap` + 트랙을 `minmax(max-content,1fr)` |
| 정적 원반 | 임팩트 낮음 | conic-gradient + 느린 spin(16s) + 이동 하이라이트 스윕 |
| 조작 결과가 미묘 | "바뀌긴 하는데 눈에 안 보임" — RUN30 초안은 여섯 결과가 전부 L\*18~24라 구분이 안 됐다 | 결과를 **두 겹으로** 보여라: 조작 상태 자체를 그림으로(3색 띠) + 최종 결과. 값만 바뀌는 건 인터랙션이 아니다 |
| 재정렬 UI가 드래그 전용 | 터치·키보드·스크린리더에서 죽는다 | 드래그 + **↑↓ 버튼 + 방향키**를 항상 함께. 재렌더 후 `focus()` 복귀까지 |

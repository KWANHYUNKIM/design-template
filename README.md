# 랜딩 템플릿 24종 — 파일 하나 열면 끝

빌드 도구도, 설치도, 계정도 필요 없는 **한국어 랜딩 페이지 템플릿** 모음입니다.
HTML 한 장 안에 스타일과 스크립트가 전부 들어 있어서, 내려받아 더블클릭하면 바로 열립니다.

**무료입니다.** 상업적 사용·수정·재배포 모두 가능하고 출처를 밝히지 않아도 됩니다.

```bash
git clone https://github.com/KWANHYUNKIM/design-template.git
cd design-template
python3 -m http.server 5500
# 브라우저에서 http://localhost:5500 접속
```

파일 하나만 필요하면 클론 없이 `templates/` 에서 원하는 것만 내려받으면 됩니다.

---

## 쓰는 법

**1. 내려받기** — 갤러리에서 원하는 카드의 `내려받기`를 누릅니다. HTML 파일 하나가 저장됩니다.

**2. 색·글자·간격 바꾸기** — 파일 맨 위 `:root` 에 토큰이 모여 있습니다. 값만 바꾸면 페이지 전체가 따라 바뀝니다.

```css
:root{
  --ink:#0d1114;   /* 배경 */
  --fg:#eef2f4;    /* 본문 */
  --k:#ffd400;     /* 포인트색 — 하나만 씁니다 */

  /* 타입 스케일 — 모듈러 1.25배. 모든 font-size가 이걸 참조합니다 */
  --t-xs:12px; --t-sm:14px; --t-base:16px; --t-md:20px;
  --t-lg:25px; --t-xl:31px; --t-2xl:39px; --t-3xl:49px;

  /* 간격 스케일 — 4배수 */
  --s1:4px; --s2:8px; --s3:12px; --s4:16px; --s5:24px;
  --s6:32px; --s7:40px; --s8:56px; --s9:80px; --s10:120px;
}
```

**3. 내용 채우기** — 본문 텍스트와 이미지 주소를 바꾸면 끝입니다.

---

## 템플릿이 지키고 있는 것

각 파일은 아래를 이미 처리해 둔 상태입니다. 손대지 않아도 되고, 고칠 때 깨뜨리지만 않으면 됩니다.

| 항목 | 내용 |
|---|---|
| **한글 줄바꿈** | `word-break:keep-all` — 없으면 "디스플레이 산세리/프." 처럼 단어 중간이 끊깁니다 |
| **웹폰트** | Pretendard를 `<link>` 로 실제 로드 — 이름만 적으면 그 폰트가 깔린 기기에서만 보입니다 |
| **모바일** | 390px부터 대응. sticky/스크럽류는 900px 이하에서 캐러셀 등으로 폴백 |
| **모션 접근성** | `prefers-reduced-motion` 에서 애니메이션 정지 + 정적 폴백 |
| **이미지 실패** | 모든 `<img>` 에 `onerror` 그라디언트 폴백 — 깨져도 레이아웃이 무너지지 않습니다 |
| **스크롤 복원** | 재방문 시 페이지 중간에서 열리는 문제를 막는 가드 |
| **타입 스케일** | 하드코딩 `font-size` 0개. 전부 `--t-*` 토큰 참조 |
| **캡처 모드** | `?capture=1` — 리빌·핀·애니를 끄고 펼친 정적 스냅샷 (디자인 툴 반출용) |

```
index.html          갤러리 (미리보기 + 내려받기)
log.html            제작 기록 — RUN마다 무엇을 어떻게 바꿨는지, 채점 결과
templates/          템플릿 24종
EVOLUTION.md        디자인 진화 로그 — 챔피언·검증된 학습·점수 이력
design-automation-workflow.md   생성 파이프라인 규격
```

---

## 이게 어떻게 만들어졌나

한 번에 24개를 찍어낸 게 아니라, **RUN 하나씩 만들고 채점해서 다음 RUN이 그 점수를 넘으려 하는 루프**로 쌓았습니다.

- 매 RUN은 `EVOLUTION.md` 의 챔피언·학습을 먼저 읽고 시작합니다
- 만든 뒤 8개 기준(타이포·컬러·여백·임팩트·모션·설득력·오리지널리티·완성도)으로 채점합니다
- **채점은 만든 주체가 아닌 독립 크리틱이 합니다** — 자기 작품을 자기가 후하게 보는 걸 막기 위해서입니다
- 크리틱이 찾은 결함을 고치고, 새로 배운 것을 `EVOLUTION.md` 에 적습니다

그래서 `EVOLUTION.md` 에는 실패 기록이 그대로 남아 있습니다. 예를 들면:

> `71개국`(국가) + 라벨 `지원 언어`(언어)는 읽는 순간 가짜 티. 발명한 스펙일수록 단위를 정확히.

> 실사 사진은 캡션이 말하는 그 대상인지 **눈으로 열어** 확인할 것. 로드 검증은 "이미지가 뜨는가"만 보장하고 "그 이미지가 맞는가"는 보장하지 않는다.

템플릿을 고칠 때 참고하시면 같은 함정을 피할 수 있습니다.
